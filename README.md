# hotel_booking_analysis
Hotel Booking Data Analysis using Python, Power BI and Data Visualization
Анализ бронирований отелей
Описание проекта
Данный проект посвящён анализу данных о бронированиях отелей. Основная цель проекта — изучить данные о бронированиях, выявить основные закономерности и тенденции, а также представить результаты анализа с помощью визуализаций.

Используемые инструменты
Python

Google Colab

Pandas

Matplotlib

Power BI

Microsoft PowerPoint

Структура проекта
data/ — исходный и очищенный датасеты

notebook/ — ноутбук Google Colab с очисткой и анализом данных

powerbi/ — файл Power BI с визуализациями и дашбордом

presentation/ — итоговая презентация в формате PDF

Подготовка данных
Исходный датасет был обработан и очищен с использованием Python в Google Colab. В процессе подготовки данные были проверены, очищены и преобразованы для дальнейшего анализа и визуализации.

В проекте представлены как исходный, так и очищенный датасеты, чтобы можно было увидеть процесс подготовки данных.

Исследовательский анализ данных
В рамках проекта был проведён исследовательский анализ данных (EDA). Были изучены основные характеристики бронирований и выявлены закономерности в данных.

Для представления результатов были созданы различные графики и визуализации.

Визуализация в Power BI
Для создания интерактивных визуализаций и дашборда использовался Power BI. Визуализации позволяют наглядно представить основные результаты анализа и взаимосвязи между различными показателями.

Презентация
Основные результаты проекта представлены в итоговой презентации в формате PDF. Презентация содержит основные этапы анализа, графики и полученные результаты.

Заключение
Проект демонстрирует полный процесс работы с данными: от исходного датасета и его очистки до исследовательского анализа, создания визуализаций в Power BI и представления итоговых результатов.
